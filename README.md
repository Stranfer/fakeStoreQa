# fakeStoreQa
# Пет-проект по обеспечению качества

В рамках проекта я прошёл полный цикл: от анализа требований и создания тестовой документации до верификации API, баз данных и проверки серверной валидации данных.

Используемые инструменты и технологии
*   **Тест-дизайн:** Google Таблицы (написание ТЗ, позитивных и негативных тест-кейсов).
*   **Тестирование API:** Postman (коллекции запросов, работа с переменными окружения).
*   **Сниффинг трафика:** Fiddler Classic (перехват, анализ и модификация HTTP/HTTPS запросов).
*   **Базы данных:** SQL (составление запросов на выборку, агрегацию, группировку и объединение таблиц).

---

## 📂 Структура репозитория

### 1. 📁 [Техническое задание и тест-кейсы]
Содержит файл со ссылкой на интерактивную Google Таблицу. 
*   **Вкладка 1:** Техническое задание для формы регистрации пользователя (спецификация полей ввода, правила валидации, требования к UI).
*   **Вкладка 2:** Набор тест-кейсов, разделенных по группам (позитивные сценарии, негативные проверки лимитов, валидация интерфейса).

### 2. 📁 [Коллекция Postman]
В папке находятся экспортированные файлы для работы с API магазина FakeStoreAPI (сущности Carts и Products):
*   Файл коллекции запросов (`.json`).
*   Файл настроек окружения / Environment (`.json`).

### 3. 📁 [Fiddler]
Практический кейс по тестированию серверной валидации. В папке находятся 3 скриншота, демонстрирующие обход клиентских ограничений браузера:
1.  Перехват оригинального HTTP-запроса регистрации.
2.  Модификация тела запроса (подмена пароля на невалидный).
3.  Верификация ответа сервера.

### 4. 📁 [SQL запросы]
Файл со скриптами проверочных запросов к базе данных, которые имитируют работу QA по верификации данных пользователей, продуктов и корзин после выполнения тестов.
